# Official PowerPoint template: layouts and sample slides

File: `assets/quanti-template-cz.potx` (Czech labels; the English twin `Quanti_PPT_Template_ENG.potx` is in
the workshop folder `brand/templates/`). Theme **Quanti Theme**: dk1 purple `#4D1254`, dk2 pink `#DF2686`,
lt1 white, lt2 black `#040505`, accents = the six secondary colours. Theme font Arial (system font); the
layouts set **Montserrat** on headings and body, so text placed in a placeholder is already right.
Slide size 16:9 (12192000 × 6858000 EMU).

charts, timelines, process and organisation diagrams and tables, **duplicate the sample slide below
with `add_slide.py` and replace its text and data**: the shapes are already in the brand colours.

organisation, cycle); 41–46 are table layouts.
